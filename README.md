# 一曼生日网站 · Prototype 01

这是“浅色纸张小世界 + 微光粒子入口 + 互动安安 + 纸质信件”方向的第一版完整原型。

当前固定版本：`v1.0.0`。这是不含背景音乐的第一版；以后加入音乐时可以继续发布为 `v2.0.0`，第一版仍可通过 Git 标签完整恢复。

计划发布仓库名：`1man-birthday`。正式的 GitHub Pages 地址格式为 `https://<GitHub用户名>.github.io/1man-birthday/`。页面使用 `noindex` 降低被搜索引擎收录的概率，但知道完整网址的人仍可正常访问。

需要替换正文时，直接查看 [`CONTENT-GUIDE.md`](CONTENT-GUIDE.md)。它按页面列出了文字所在文件、可搜索的关键词和安全修改示例。

## 2026-09-30：上海建筑与郁金香粒子聚合

通过口令后，四栋上海建筑和标题下方的郁金香会先由散落粒子聚合成轮廓，再与原始透明 PNG 交叉淡入。动画结束后仍显示原图，因此最终构图、颜色与清晰度不变。安安嘴边的隐形命中区域也从较小的嘴部范围扩大到脸部中央区域，拖动猫条和玩具不再要求像素级对准。

HTML 仍只负责两张原图；CSS 在聚合期间暂时隐藏原图；`particle-scene.js` 从图片透明像素采样目标点；`script.js` 在入口完成后启动聚合并在结束时恢复原图。Three.js 负责粒子，GSAP 负责聚拢和交叉淡入的节奏。

## 2026-09-30：安安互动页与轻量翻页定稿

猫咪章节已经改成安安的单场景互动：先摸两次安安，随后可以把散落的玩具或猫条拖到嘴边。玩具会被拒绝；猫条会消失并解锁可翻面的气泡，背面是安安送给一曼的生日祝福。安安使用 `assets/images/anan-digital-avatar-v1.png` 透明素材，结尾页也复用同一张图，只保留“摸一下再走”和轮换出现的轻松反馈。

全站导航现在只有直接浮在页面上的 ↑ / ↓ 两个圆形按钮，没有底部矩形条和页码。口令输入区域使用径向透明渐变消解白框边缘；通过口令后直接进入上海建筑首页，不再停留在独立的粒子祝福页。原来的郁金香被整理成透明素材，放在首页标题下方。

## 2026-09-30：入口粒子猫头与新版猫爪

密码页删除了满屏随机粒子、CSS 星点和椭圆轨道，只在左上角显示参考 `assets/images/particle-cat-head-reference.jpg` 重绘的粒子猫头。猫头粒子带有不同的 Z 轴深度，整体围绕自身中心缓慢左右转动，因此会产生轻微立体感，但不会干扰中间的口令输入。口令正确后，猫头柔和淡出，直接打开上海建筑首页。

篮球页到小猫页的过渡猫爪改为参考 `assets/images/particle-cat-paw-reference.jpg` 的云朵状轮廓、四枚趾垫和左侧下垂线条。两种图形都由 Canvas 路径生成采样点，Three.js 负责绘制和旋转，GSAP 负责猫头移动、粒子变形和淡入淡出的节奏。

## 2026-09-30：统一为浅色纸张主题

入口、首页、篮球、小猫、祝福、信件与结尾现在统一使用接近篮球页的暖灰纸张底色。深色页面原有的文字、卡片边界、按钮和装饰线都改成墨色与暖棕色；Three.js 粒子也从浅色发光粒子改为适合浅底的墨蓝与暖棕，并使用普通透明混合，避免浅底上失去轮廓。页面仍通过非常轻的蓝灰光晕和纸面线条区分章节，不再依赖深浅背景跳变。

## 2026-09-30：首页上海地标手绘图

`Happy Birthday，一曼` 首页右侧使用透明背景的上海地标手绘插画，包含东方明珠、环球金融中心、金茂大厦和上海中心；标题下方增加 `assets/images/particle-tulip-bouquet-v1.png`。HTML 负责引用两张 PNG，CSS 负责位置、大小、透明度和与纸张背景的融合；JavaScript、Three.js 与 GSAP 均不参与这两张静态插画。

## 2026-09-30：篮球页改为两场景互动

篮球章节不再使用三栏卡片，而是分成“投篮互动”和“文字故事”两个前后场景。第一幕先只露出左上角的一小块 6 号球衣，点击后球衣斜着展开，提示由“穿上你的球衣”切换为“把球投进篮筐”，篮球也在这时才解锁拖动。把球拖进右侧篮筐后，画面自然淡出并进入正式篮球文字页，同时开放“下一页”。

这段互动的状态顺序是：`等待球衣 → 可以投篮 → 进入故事`。它类似 Qt 中根据状态启用或禁用控件：球衣没有展开时，篮球按钮的 `disabled` 属性为真；完成投篮后，`courtStoryReached` 变为真，章节导航才允许继续。

## 2026-09-20：Three.js 粒子变换

现在只保留两种真正需要的粒子用途：口令页左上角的轻微旋转猫头，以及从篮球页翻到安安页时的“篮球变猫爪”。信件页和结尾页不使用粒子，让文字与安安成为主角。

HTML 只提供一个全屏透明 `canvas`；CSS 负责画布层级；`script.js` 决定动画何时播放；
`particle-scene.js` 使用 Three.js 保存和绘制粒子坐标，GSAP 只负责控制聚拢、停留和散开的时间节奏。

关键代码：

```js
await window.BirthdayParticles.hideGateCat();
await this.morphTo(paw, 0.82, "power3.inOut", 1050);
this.geometry.attributes.position.needsUpdate = true;
```

可以把它理解为：Three.js 是不断重绘的 `QOpenGLWidget`，GSAP 是时间轴，`script.js` 中的翻页事件则类似 Qt 的 signal/slot。

## 2026-09-20：按钮翻页更新

右侧章节目录已移除。只使用底部“上一页 / 下一页”依次阅读，滚轮不控制翻页。
长祝福、长信会先在当前章节内分屏阅读，再进入下一章；返回时会回到上一章末尾。

这次模块中，HTML 只提供两个按钮；CSS 固定阅读舞台、隐藏滚动条并绘制直接浮在背景上的柔和圆形按钮；
JavaScript 保存当前章节编号并处理前后翻页。Three.js 和 GSAP 均未参与，
淡入使用浏览器原生动画。它类似 Qt 的 stacked widget：当前索引决定显示哪个页面。

关键代码（script.js）：

```js
previousPage.addEventListener("click", () => turnPage(-1));
nextPage.addEventListener("click", () => turnPage(1));
chapter.hidden = position !== index;
chapter.scrollTo({ top, behavior: "smooth" });
```

前两行把按钮事件连到翻页函数，第三行只显示目标页面，第四行用于长内容的分屏阅读。
以下第一版“章节滚动”说明为旧实现记录，已由这一版替代。

## 2026-09-30：安安的透明数字分身

互动页与结尾彩蛋统一使用 `assets/images/anan-digital-avatar-v1.png`。素材依据用户上传的安安照片制作成透明背景数字分身。HTML 负责引用图像和放置玩具，
CSS 负责大小、阴影、气泡翻面和玩具外形，JavaScript 负责抚摸次数、拖拽命中和喂食状态。Three.js 与 GSAP 不参与这段页内互动。
关键实现是 `<img src="assets/images/anan-digital-avatar-v1.png">`；把图像独立成一个文件后，
以后只替换这一个 PNG，就能同步更新页面中的所有小猫。

这一版的目标不是完成所有视觉特效，而是先确认：

- 故事能否从轻松自然地走向安静；
- 口令入口是否有仪式感；
- 篮球、猫和共同记忆是否出现得自然；

## 如何打开

直接双击 `index.html`，用常见电脑浏览器打开即可。

当前口令：

```text
Tenacious Goddess
```

```js
const ACCESS_CODE = "Tenacious Goddess";
```

## 需要准备的素材

### 1. 入口暗号

请准备 2～3 个候选暗号。最好满足：

- 她能自然想到；
- 不是姓名、生日等太容易猜到的内容；
- 不考验她是否记得某个沉重情感时刻；
- 输入不宜太长。

### 2. 篮球部分

- 1～2 张篮球相关照片；
- 一件她担任队长时做过的具体事情；
- 一个与训练、比赛或组织队伍有关的轻松细节；
- 如果照片涉及其他人，请确认可以使用或进行裁切。

### 3. 安安部分

- 当前透明数字分身已经可以直接使用；
- 如果希望进一步贴近安安，可再提供一张正面、光线均匀、无遮挡的全身照；
- 也可以补充安安真实喜欢的玩具或零食，替换目前的 CSS 小道具。

### 4. 只有你们知道的内容

第一轮先准备 5～8 条候选，最终只选 3～5 条：

- 她说过的一句话；
- 一个小梗；
- 一件很小但你一直记得的事；
- 一次吃东西、聊天或分享视频的片段；
- 一段适合让她笑出来，而不是感到负担的内容。

### 5. 上海与生活照片

- 她自己拍的校园、街道、窗灯或天空；
- 不需要是地标，也不要假装是你们共同去过的地方；

### 6. 最终信件

暂时不用写完整。之后可以先提供未经整理的素材：

## 模块学习说明

### 模块 A：口令入口

1. **HTML 负责什么？**
   页面只保留输入框和提交按钮。`form` 就像 Qt 中一组共同完成任务的输入控件。
2. **CSS 负责什么？**
   让入口覆盖整个窗口，并绘制深夜、轨道、微光和开门淡出效果。
3. **JavaScript 负责什么？**
   监听表单提交、比较口令，并决定轻微抖动还是打开网站。这很像 Qt 的 signal/slot：用户提交是 signal，验证函数是 slot。
4. **Three.js 是否参与？**
   参与。入口左上角是轻微立体旋转的粒子猫头，口令正确后会柔和淡出。
5. **GSAP 是否参与？**
   参与。它控制粒子聚拢、停留、散开和淡出的时间。
6. **最关键的代码：**

   ```js
   accessForm.addEventListener("submit", (event) => {
     event.preventDefault();
     if (normalizeCode(accessInput.value) === normalizeCode(ACCESS_CODE)) {
       openBirthdaySite();
     }
   });
   ```

7. **为什么这样实现？**
   先用浏览器原生表单机制，逻辑清楚，按 Enter 也能进入，方便初学者理解。

### 模块 B：按钮翻页

1. **HTML 负责什么？**
   每一幕都是一个有唯一 `id` 的 `section`。
2. **CSS 负责什么？**
   固定一屏浅色纸张舞台，只显示当前章节，并把上下按钮直接悬浮在背景上。
3. **JavaScript 负责什么？**
   保存当前章节编号，响应“上一页 / 下一页”，并显示目标章节；页面不显示页码。
4. **Three.js 是否参与？**
   只参与篮球页到小猫页的粒子过渡，不负责普通翻页。
5. **GSAP 是否参与？**
   只控制特殊粒子转场；普通章节淡入仍使用浏览器原生动画。
6. **最关键的代码：**

   ```js
   previousPage.addEventListener("click", () => turnPage(-1));
   nextPage.addEventListener("click", () => turnPage(1));
   chapter.hidden = position !== index;
   ```

7. **为什么这样实现？**
   它类似 Qt 的 `QStackedWidget`：索引决定当前显示哪一页，按钮点击就是切换索引的信号。

### 模块 C：篮球两场景互动

1. **HTML 负责什么？**
   提供球衣、篮球、篮筐、操作提示，以及进球后显示的独立文字场景。
2. **CSS 负责什么？**
   绘制 6 号球衣、篮球和篮筐，安排球场构图，并负责球衣滑出、投篮成功和两幕淡入淡出的视觉状态。
3. **JavaScript 负责什么？**
   控制“等待球衣 → 可以投篮 → 进入故事”的状态，处理指针拖动、命中篮筐判断，并锁定或开放“下一页”。
4. **Three.js 是否参与？**
   这段球衣和投篮互动本身不参与；从篮球章节翻到小猫章节时，仍使用 Three.js 做篮球变猫爪的粒子过渡。
5. **GSAP 是否参与？**
   这段互动本身不参与，使用 CSS transition 保持轻巧；GSAP 只控制离开篮球页时的粒子时间线。
6. **最关键的代码：**

   ```js
   dragBasketball.disabled = false;
   dragBasketball.setPointerCapture(event.pointerId);
   if (insideRim) scoreBasketball();
   courtStoryReached = true;
   ```

7. **为什么这样实现？**
   原生 Pointer Events 同时适合鼠标拖动，也不需要额外库；把两幕都保留在同一个章节中，可以让投篮后的转场连贯，同时不影响全站统一的上下翻页逻辑。

### 模块 D：安安互动页

1. **HTML 负责什么？**
   放置安安图片、气泡、嘴边命中区域，以及小鸭子、毛线球、小老鼠和猫条四个可拖动物件。
2. **CSS 负责什么？**
   完成左右构图、玩具外形、猫咪阴影、抚摸动作和气泡的 3D 翻面。
3. **JavaScript 负责什么？**
   记录抚摸次数，处理 Pointer Events 拖拽，判断道具是否碰到嘴边，并切换气泡内容与互动阶段。
4. **Three.js 是否参与？**
   不参与这一页的交互；它只负责进入本页之前的篮球变猫爪过渡。
5. **GSAP 是否参与？**
   不参与页内互动，动作由 CSS transition / animation 完成。
6. **最关键的代码：**

   ```js
   ananPetCount += 1;
   prop.setPointerCapture(event.pointerId);
   if (hitMouth && prop.dataset.kind === "treat") feedAnan(prop);
   ananBubble.classList.toggle("is-flipped");
   ```

7. **为什么这样实现？**
   把“摸猫”和“喂食”写成明确状态，类似 Qt 控件根据成员变量切换 enabled / visible；以后替换文案或玩具时，不必重做页面结构。

### 模块 E：信封与信件

1. **HTML 负责什么？**
   创建信封按钮和最初隐藏的信纸。
2. **CSS 负责什么？**
   用几个图层表现信封，并设置翻盖和信纸升起的状态。
3. **JavaScript 负责什么？**
   点击后改变信封状态、显示信纸，并把页面滚动到适合阅读的位置。
4. **Three.js 是否参与？**
   不参与。最终也建议让 Three.js 在这里退场。
5. **GSAP 是否参与？**
   第一版不参与；后续可用于更自然的开信节奏。
6. **最关键的代码：**

   ```js
   openLetterButton.classList.add("is-open");
   openLetterButton.setAttribute("aria-expanded", "true");
   letterSheet.hidden = false;
   letterSheet.scrollIntoView({ behavior: "smooth" });
   ```

7. **为什么这样实现？**
   信件内容仍然是普通 HTML，因此容易编辑、容易阅读，也不会被复杂动画绑住。

## 版本与后续音乐

当前版本先作为 `v1.0.0` 保存。以后选好音乐后，只需要把音频放入 `assets/music/`，再增加一个 `<audio>` 元素和少量播放控制代码，即可形成第二版，不需要推翻现有页面。

建议第二版包含：点击 `Enter` 后低音量淡入、循环播放、右下角暂停按钮，以及打开信件时自动降低音量。音乐文件不要提交来路不明或没有使用权限的版本。

部署到 GitHub Pages 后仍然可以继续修改：每次推送到发布分支，线上页面都会更新；`v1.0.0` 标签会保留当前无音乐版本。
